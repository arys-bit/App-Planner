# Ary Estudos — App-Planner

Código-fonte do aplicativo de planejamento e estudos de Ary.

Aplicativo ativo: https://ary-estudos.anarabjs.chatgpt.site

Este repositório contém o código; GitHub Pages não executa o backend, banco D1, arquivos R2 e autenticação deste aplicativo. Dados pessoais e credenciais não são incluídos.

O projeto fica na raiz deste repositório. Componentes principais: `app/study-app.tsx` e `app/globals.css`. Para alterações visuais, preserve as funcionalidades, APIs, armazenamento e autenticação existentes.

Instale as dependências com `pnpm install --frozen-lockfile`. Verifique tipos com `pnpm exec tsc --noEmit`. Consulte `README.md` para instruções técnicas de desenvolvimento.

Um push no GitHub não publica automaticamente alterações no ChatGPT Sites.
